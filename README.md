# GearSentry: issues

Bug reports and feature requests for **GearSentry**, the World of Warcraft: Forever addon that
spots gear upgrades in your bags and offers to equip them.

**[Open a new issue](../../issues/new/choose)** and pick the form that fits:

- **Lua error**: you got a BugSack report or the default error pop-up.
- **Wrong upgrade suggestion**: GearSentry called something an upgrade that isn't, or missed one.
- **Bug**: something else broke or didn't happen.
- **Feature request**: an idea or a missing option.

The most useful thing you can paste for a suggestion problem is the output of `/gs eval` followed by
the item (type `/gs eval `, then shift-click the item into chat). It shows exactly how GearSentry
scored that item.
